# SkillBridge 🎓

### Bridging the Gap Between Learning and Job Readiness

SkillBridge is an AI-powered learning platform designed to help students improve their technical knowledge and prepare for real-world job opportunities.

It brings learning resources, practice questions, mock tests, learning roadmaps, interview preparation, and AI-powered assistance together in one platform.

## 🚀 Project Overview

Many students learn theoretical concepts but struggle to apply them in practical situations and meet industry requirements.

SkillBridge aims to address this challenge by providing a centralized platform where students can learn, practice, evaluate their knowledge, and improve their career readiness.

## ✨ Key Features

- **User Authentication:** Registration and login functionality.
- **Learning Content:** Organized technical learning materials.
- **Practice Questions:** Topic-based practice for improving technical skills.
- **Mock Tests:** Assess knowledge through practice assessments.
- **Learning Roadmaps:** Structured learning paths for different technologies.
- **Interview Preparation:** Resources to prepare for technical interviews.
- **AI Chatbot:** AI-powered assistance for learning-related questions.
- **Progress Tracking:** Monitor learning progress.

## 🏗️ System Architecture

The application follows a frontend–backend architecture.

1. The frontend provides the user interface.
2. JavaScript handles user interactions and API requests.
3. The Flask backend processes application requests.
4. SQL Server manages application data.
5. The Gemini API generates AI chatbot responses.
6. The frontend displays the results to users.

## ⚙️ Local Setup

### 1. Clone the repository

```bash
git clone https://github.com/Nadendla25/skill-bridge2.git
```

### 2. Navigate to the project folder

```bash
cd skill-bridge2
```

### 3. Install backend dependencies

```bash
python -m pip install Flask flask-cors google-genai pyodbc
```

### 4. Configure environment variables

Configure the required database connection settings and Gemini API key securely in your local environment.

Do not upload API keys or passwords to GitHub.

### 5. Run the Flask backend

```bash
python ai_assistant.py
```

### 6. Open the frontend

Run the frontend using VS Code Live Server or your preferred local web server.
